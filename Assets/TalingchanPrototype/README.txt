เปิด Assets/TalingchanPrototype/Scenes/GameplayPrototype.unity แล้วกด Play
Scene หมู่บ้านเดิม BanRimKhlong ไม่ได้ถูกเขียนทับ

รอบที่เล่นได้
1. อ่านบทเกริ่นชั่วคราว เริ่มในบ้านหลังแรก จุดพักชั่วคราว
2. ออกจากบ้าน ไปบ้านร้างหลังที่สองริมถนน เปิดประตูด้วย E
3. อ่านบันทึก เก็บเศษไม้ 3 ผ้าเก่า 2 เศษพระ 1 ชิ้น
4. เดินขึ้นเหนือไปวัด คุยกับพระแล้วส่งของ จบรอบทดลอง
5. ทดลองถือ/วาง/ปาหินหรือขวด เสียงกระแทกล่อคนไล่ได้
6. อยู่นอกจุดปลอดภัยและไม่ขยับ 120 วินาที จะมีคนไล่
   อ่าน คุย กระเป๋า วงล้อ คัทซีน ไม่นับ AFK และไม่หยุดเวลาโลก
   เข้าบ้านพักชั่วคราวหรือหนีจนเสียการมองเห็นเพื่อหยุดการไล่
7. ถูกจับจะโหลดจุดบันทึกล่าสุด พร้อมของและเควส ณ เวลาที่บันทึก

ปุ่ม
WASD / เมาส์ : เดิน / มอง   Shift : วิ่ง   Space : กระโดด
E : เก็บของ / อ่าน / เปิดประตู / คุย / บันทึกที่สมุด
Tab : เปิด/ปิดกระเป๋า 10 ช่อง
กด Alt ค้าง : วงล้อ เลื่อนเมาส์หรือคลิกเลือกช่อง ปล่อยเพื่อกลับ
1–9 และ 0 : เลือกช่องขณะเดิน
X : ใช้ของที่เลือก   Q : วางของที่เลือก 1 ชิ้น
คลิกขวา : ถือของจากพื้น / วาง   คลิกซ้ายขณะถือ : ปา
F : หยิบ/เก็บไฟฉายซ้าย   G : เปิด/ปิดไฟ
Enter / Esc : ปิดหน้าจออ่าน   Esc ตอนเดิน : ปลดเมาส์
F5 : บันทึกสถานะโดยใช้ตำแหน่งจุดบันทึกล่าสุด
F9 : โหลดจุดบันทึก
F8 : เรียกคนไล่ทันที (ทดสอบนอกจุดปลอดภัย)
F7 : ทดสอบตาย

ปรับใน Inspector
Hierarchy > PROTOTYPE SYSTEMS - Inspector settings here
  GameplaySettings.asset : ช่องกระเป๋า เวลา AFK ปุ่ม ระยะเก็บของ
  การปา UI ข้อความเกริ่น การเซฟ และค่าเริ่มต้นทั้งหมด
  ปุ่มต่างๆ มีผลเมื่อเริ่ม Play ใหม่ ส่วนค่าตัวเลขส่วนใหญ่ใช้ทันที
Data/Items/*.asset : ชื่อของ คำอธิบาย จำนวนซ้อนสูงสุด
  ถือ/ทิ้ง/ปาได้ไหม การใช้ น้ำหนัก และ prefab
Data/Quests/*.asset : ข้อความ ของที่ต้องใช้ เงื่อนไขก่อนหน้า
  flags รางวัล การหักของ และเควสที่ต้องครบก่อนจบ
PURSUER : จุดเกิด ความเร็ว เวลาเตือน ระยะเห็น/จับ/ได้ยิน
  เวลาตรวจเสียง คูลดาวน์ เวลาหลุด และโมเดล
PROTOTYPE CONTENT : จุดเกิดของ บันทึก พระ ประตู
  จุดบันทึก safe zone forbidden zone และเหตุการณ์เงาผี
PrototypeAudio : คลิปชั่วคราว ระดับเสียง และจังหวะฝีเท้า
Player > SandboxFlashlight : ไฟ ปุ่ม ระยะ เวลาและท่าหยิบ/เก็บ
PrototypeHud : สี ขนาดช่อง ตำแหน่งหน้าจอ และการแสดง debug
PrototypeGame : มีปุ่มทดสอบใน Inspector ขณะ Play

ของไม่เกิดใหม่ในรอบเดิม โหลดแล้วคืนสถานะ ณ จุดเซฟ
New Run เริ่มสถานะใหม่ เปิดสุ่มจุดของได้หากใส่ New Run Spawn Candidates
การลดช่องกระเป๋าไม่ลบของ: ของส่วนเกินวางใกล้ผู้เล่น

ค่าทดลองที่ยังต้องประชุม
- ปลอดภัย/เซฟใช้บ้าน 1 ไปก่อน ตำแหน่งจริงยังไม่ยืนยัน
- จำนวนซ้อนสูงสุดกำหนดต่อไอเทม (ไม่ใช่ข้อสรุปสุดท้าย)
- ตอนนี้ทดสอบรวบรวมและส่งของ ยังไม่มีสูตรคราฟ/ปลุกเสกฉบับจริง
- คนไล่และเงาผีใช้โมเดลชั่วคราว ยังไม่ใช่ภาพสุดท้าย
- เสียงชั่วคราว CC0 เครดิตใน TalingchanVillage/Audio/Temporary/CREDITS.txt
- เรื่องผีอื่น บอส คัทซีนจริง การคลาน/ปีน/มองลอด/แอบ ยังไม่อยู่ในรอบนี้
- ระบบโทรศัพท์ถูกปิดเฉพาะ Scene ทดลอง เก็บของเดิมไว้ใน Scene หมู่บ้าน

Navigation baked จาก collider หมู่บ้าน ประตูถูกละจาก bake เพื่อให้เปิดเดินผ่านได้
ถ้าแก้โครงสร้างแมพ ใช้เมนู Talingchan > Rebake prototype navigation only
